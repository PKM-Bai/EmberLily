# EmberLily

面向 GBA《火焰纹章》官方作品及改版的 Android 双屏增强游玩项目。上屏运行原游戏，下屏提供战局信息、军团与背包管理、培养规划、章节攻略和结构研究工具。

主要验收设备为 AYN Thor 16GB＋1TB。**M0 已通过，M1 余项与 M2 实施中**。当前 `0.0.4-m2-preview` 接入指定 FE8 中文语音版及 FE7 日版／汉化版的光标详情、固定对比、RAM 快照与实验 HP 编辑／恢复。上屏移除虚拟键、隐藏系统栏；R04 的已适配空闲战场支持真实地图扩景。FE7 两份构建分别通过序章场景、编辑恢复和跨引擎隔离测试；汉化名称暂显示文本编号。正常准备背包、更多场景和新版 Thor 整体验收仍待完成，当前不是 M1/M2 阶段关闭或 v0.1 发布。

## 功能方向

| 工作区 | 已确认的首版范围 |
| --- | --- |
| 战场 | 光标跟随详情、固定单位对比、单位与地形透视、移动及攻击覆盖、游戏当前战斗预测同步 |
| 军团 | 全军和仓库搜索、筛选、比较；准备画面整理；战场合法交换、补给、装备和道具使用 |
| 培养 | 目标等级与职业、成长预期及概率、转职路线与资源、多方案比较和存档进度跟踪 |
| 攻略 | 当前章节目标、外传、招募、对话、地点及已解析事件清单，跟踪实际完成状态 |
| 研究 | 数据结构、事件脚本与标记、状态差异；在独立实验分支编辑运行状态并恢复 |

首版的下屏直接操作以背包和仓库为核心，战场移动、攻击等沿用上屏原生操作。开发阶段开放全部已解析数据；未知机制明确标记，后续加入独立功能开关及默认方案。

## 适配与交付顺序

FE8 最小双屏读写闭环 → FE7 基础适配 → 指定中文构建的《天地之剑》 → 补齐三者的首版功能 → FE6。

用户已调整近期顺序：完成上屏显示改进和真实扩景后提前实施 M2；M1 尚未完成的任务继续跟踪，不因接入 FE7 自动关闭。

M1 是内部技术验证，M3 是改版接入验证；M5 通过完整验收后作为 v0.1 发布节点。FE6 在 M6 达到相同标准后加入。兼容性按精确 ROM 构建与具体能力验证；目前 R04、R02、R06 开放已验证的最小实时信息和 HP 实验编辑，不宣称整部作品或同名改版完整支持。

## 技术与开源路线

采用 Kotlin／Jetpack Compose、C/C++ JNI 和 mGBA。选择性复用 [PokeDaisy](https://github.com/lidor30/pokedaisy) 的通用实现和设备经验，重新建立火纹数据模型、界面与操作状态机。

已登记 FE8 日版与中文语音版、FE7 日版与汉化版、指定《天地之剑》及 FE6 的本地文件。FE8 两份文件均为 `BE8J`，M1 需要核验日版及中文构建布局。烈火 Plus 因文件头校验不符未登记。游戏文件、存档和本地路径不随项目分发；M0 宿主验收不等于完成这些游戏的火纹语义适配。
